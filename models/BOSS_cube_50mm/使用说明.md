# BOSS 直聘 · 50 毫米双色正方体

模型已在 Bambu Studio 2.8.2.61 中成功导入并检查。根据你的最新要求，仅生成模型并导入；未切片、未发送打印任务。

## 文件

- `BOSS_cube_50mm.3mf`：首选文件，包含青色主体和白色文字，两个独立部件组成一个对象，保留颜色及相对位置。
- `body_cyan.stl`：50 × 50 × 50 毫米主体。
- `lettering_white.stl`：白色凸字；保留装配坐标，底部在 Z=50 毫米。不要单独导入后让文字自动落到打印板上。
- `preview.png`：立体外观和正面预览。
- `geometry_validation.json`：尺寸、封闭网格和方向检查结果。
- `lettering_outline.json`：从原图提取的文字轮廓，单位毫米。
- 完整文件包的 `source` 目录包含生成脚本和参考图。

## 在 Bambu Studio 中打开

1. 加载 `BOSS_cube_50mm.3mf`。该文件仅保存模型，不包含具体打印机的完整工艺配置。
2. 本机版本通过“打开项目”加载时会提示“3mf 文件配置无效，仅加载几何数据”。点击“确认”即可继续；这是没有嵌入完整打印配置的提示，网格已通过检查。
3. 在“标准3mf导入颜色”对话框中保留 **2 种颜色**，确认青色和白色的对应关系，然后确认。
4. 在左侧“对象”页展开模型，应有 `Cyan body` 和 `White BOSS lettering` 两个部件。当前会话中分别对应耗材 **2（青色）**、**3（白色）**；原先的黄色耗材 1 未用于这两个部件。新会话编号可能不同，以颜色为准。
5. 若使用 STL 备用文件，请同时选择两个 STL，以“单个对象、多个部件”方式加载并保持原始相对位置。STL 本身不保存颜色。

## 尺寸与外观

- 正方体主体：50 × 50 × 50 毫米，直角。
- 白字：宽 40 毫米、高约 35.59 毫米，凸起 0.8 毫米；含白字总高 50.8 毫米。
- 字形直接提取自提供的 148 × 148 像素图片，并做轻度轮廓平滑；不是另选字体重排。
- 青色显示值为 `#53CAC6`，文字为白色。
- 有字的一面朝 +Z；背面位于 Z=0。以后摆放展示时可把这一面朝前。

已检查：所有网格封闭、法线一致、体积为正、文字与主体在 Z=50 毫米处接触；Bambu Studio 显示尺寸 50 × 50 × 50.8 毫米，文字方向和青白颜色正确，两个部件独立可选。文字由 8 个封闭连通块组成，共保留 14 个字内孔洞。

## 重新生成

完整文件包解压后，在 `source` 目录运行：

```powershell
uv run build_model.py
```

脚本自带 Python 依赖声明，会在脚本旁的 `BOSS_cube_50mm` 目录生成模型、预览和几何检查报告。参考图 `images.jpg` 必须与脚本放在一起。可修改脚本顶部的几何常量后调整相应验证尺寸。

3MF 兼容性检查参考了 Bambu Studio 官方开源导入实现：https://github.com/bambulab/BambuStudio/blob/master/src/libslic3r/Format/bbs_3mf.cpp
